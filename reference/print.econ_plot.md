# Draw an econ_plot

Draw an econ_plot

## Usage

``` r
# S3 method for class 'econ_plot'
print(x, newpage = TRUE, ...)

# S3 method for class 'econ_plot'
plot(x, ...)
```

## Arguments

- x:

  An `econ_plot` from
  [`econ_masthead()`](https://mjorden.github.io/fredscape/reference/econ_masthead.md).

- newpage:

  Start a new grid page first?

- ...:

  Ignored, for compatibility with
  [`print()`](https://rdrr.io/r/base/print.html).

## Value

`x`, invisibly.
